# Off The Clock

Premium private social rooms venue website for Dublin.

**Your space. Your friends. Your time.**

## Features

- 18+ age gate on first visit
- Cinematic homepage and room showcases (Pool, DJ, Karaoke, Gaming & Movie, VIP Chill)
- Interactive Standard / Peak pricing
- Treats & signature packages
- Full end-to-end simulated booking flow (room → date/time → duration → treats → details → review → payment → confirmation)
- FAQ, How it works, Contact, Legal
- Dark, minimal, mobile-responsive UI

## Stack

- React 19 + TypeScript
- TanStack Start / Router
- Vite 8
- Tailwind CSS v4
- Zustand (booking + age gate state)

## Develop

```bash
npm install
npm run dev        # http://localhost:8080
npm run build
npm run typecheck
```

## Note

Payment is **simulated only** — no real charges. Ready to connect a real booking backend and Stripe later.
